# P2380 [CSP-J 2025] 拼数 number

## 题目描述

Background
Special for beginners, ^_^
Description
Given two integers x and y, print the sum.
Format
Input
Two integers x and y, satisfying 0\leq x,y\leq 32767 .
Output
One integer, the sum of x and y.
Samples
Limitation
1s, 1024KiB for each test case.

## 输入输出样例 #1

### 输入 #1

```
123 500
```

### 输出 #1

```
623
```
