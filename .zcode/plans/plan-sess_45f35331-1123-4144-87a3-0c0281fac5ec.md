## 目标
在 D:\Code 仓库创建一个 GitHub Pages 静态网页，浏览展示仓库内全部 .cpp 代码与 .md 题目描述/笔记，托管于 github.com/tangyixiao/Code，上线后网址 https://tangyixiao.github.io/Code/。

## 新建文件（D:\Code 根目录，不修改现有文件）

### 1. index.html（单文件 Web 应用，纯前端、无构建）
- 常量配置：仓库 tangyixiao/Code、分支 main（置于文件顶部注释，便于修改）
- 深色主题、中文界面，左侧文件列表 + 右侧内容查看的双栏布局
- 文件列表：调用 GitHub Contents API（https://api.github.com/repos/tangyixiao/Code/contents/?per_page=1000，按 Link 头分页直到拉全）获取根目录全部文件，只保留 .cpp 和 .md，localStorage 缓存列表（带时间戳 + 手动刷新按钮，规避 60 次/小时未认证限流）
- 侧边栏功能：搜索框（按文件名/题目编号过滤）、筛选标签（全部 / C++ / Markdown）、按名称/大小排序
- 内容查看：点击文件后从 raw.githubusercontent.com/tangyixiao/Code/main/<URL编码路径> 拉取内容；.cpp 用 highlight.js 高亮并显示行号；.md 用 marked.js 渲染排版；均含 CDN 加载失败时降级为纯文本的兜底
- 文件头信息：文件名、大小、行数；工具栏含「复制代码」「新标签页打开原文」
- 友好错误提示（网络失败 / API 限流 403 / 文件不存在 404）

### 2. .nojekyll（空文件）
- 禁止 GitHub Pages 的 Jekyll 处理，避免 300MB 仓库构建超时，保证文件原样可访问

## 上线步骤（方案获批并实现完成后，由用户执行或经用户同意后代执行）
1. git add index.html .nojekyll && git commit && git push origin main
2. GitHub 网页端 Settings → Pages → Source: Deploy from a branch → 选 main / (root) → Save
3. 约 1 分钟后网站生效：https://tangyixiao.github.io/Code/

## 设计要点
- 网页通过 GitHub API/raw 实时读取 main 分支，每次 push 后网站自动更新，无需重新构建
- 两个域名（api.github.com、raw.githubusercontent.com）均返回 CORS *，页面本地双击打开也可用
- 仅新增 2 个文件，不影响仓库现有 3700+ 文件与 README 等
