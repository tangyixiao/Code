## 题目分析

给定三个非负整数 $a, b, c$，我们需要：
1. 将它们转换为二进制（无前导0）
2. 以最长的位数为基准，其他数补前导0到相同位数 $n$
3. 重新排列每个数的二进制位（保持每个数中1的个数不变）
4. 得到新的数 $A', B', C'$ 满足 $A' + B' = C'$（$n$ 位二进制加法，不溢出）
5. 在满足条件的 $C'$ 中找出最小值

## 关键观察

1. **位数限制**：设 $n = \max(\text{len}(a), \text{len}(b), \text{len}(c))$，其中 $\text{len}(x)$ 表示 $x$ 的二进制位数（当 $x=0$ 时位数为1）
2. **1的个数固定**：设 $\text{cntA}, \text{cntB}, \text{cntC}$ 分别为 $a, b, c$ 二进制中1的个数
3. **加法约束**：对于每个二进制位 $i$（0为最低位），有 $A_i + B_i + \text{carry}_i = C_i + 2 \cdot \text{carry}_{i+1}$，且最终进位 $\text{carry}_n = 0$
4. **最小化C'**：从高位到低位贪心，尽量让 $C'$ 的每一位为0

## 算法设计

使用**动态规划**结合**贪心构造**：

### 动态规划部分

定义两个DP数组：

1. **前向DP**：`f[i][a1][b1][c1][carry]`
   - 表示处理完**低i位**（0到i-1位）
   - $A$ 已用 $a1$ 个1，$B$ 已用 $b1$ 个1，$C$ 已用 $c1$ 个1
   - 当前进位为 $carry$（来自第i-1位）
   - 值表示该状态是否可达

2. **后向DP**：`g[i][a1][b1][c1][carry]`
   - 表示从**第i位开始**（处理第i到n-1位）
   - $A$ 已用 $a1$ 个1，$B$ 已用 $b1$ 个1，$C$ 已用 $c1$ 个1
   - 当前进位为 $carry$（进入第i位）
   - 值表示从该状态能否到达最终目标状态 $(n, \text{cntA}, \text{cntB}, \text{cntC}, 0)$

### 贪心构造部分

从高位到低位（i = n-1 到 0）确定 $C'$ 的每一位：
1. 优先尝试当前位设为0
2. 检查是否存在前向状态 $(i, a1, b1, c1, carry_in)$ 和选择 $(A_i, B_i)$ 使得：
   - 满足加法等式
   - 后向状态可达
3. 如果0可行则选择0，否则选择1

## 复杂度分析

- 状态数：$O(n \cdot \text{cntA} \cdot \text{cntB} \cdot \text{cntC} \cdot 2) \approx 31 \times 31 \times 31 \times 31 \times 2 \approx 1.8 \times 10^6$
- 转移复杂度：每个状态枚举 $2^3 = 8$ 种选择
- 总复杂度：约 $1.8 \times 10^6 \times 8 \approx 1.4 \times 10^7$，可接受

## C++实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int bit_len(int x) {
    if (x == 0) return 1;
    return 32 - __builtin_clz(x);
}

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    
    int n = max({bit_len(a), bit_len(b), bit_len(c)});
    int cntA = __builtin_popcount(a);
    int cntB = __builtin_popcount(b);
    int cntC = __builtin_popcount(c);
    
    // 前向DP：f[i][a1][b1][c1][carry]
    bool f[32][32][32][32][2] = {false};
    f[0][0][0][0][0] = true;
    
    for (int i = 0; i < n; i++) {
        for (int a1 = 0; a1 <= cntA; a1++) {
            for (int b1 = 0; b1 <= cntB; b1++) {
                for (int c1 = 0; c1 <= cntC; c1++) {
                    for (int carry = 0; carry <= 1; carry++) {
                        if (!f[i][a1][b1][c1][carry]) continue;
                        
                        for (int ai = 0; ai <= 1; ai++) {
                            if (a1 + ai > cntA) continue;
                            for (int bi = 0; bi <= 1; bi++) {
                                if (b1 + bi > cntB) continue;
                                for (int ci = 0; ci <= 1; ci++) {
                                    if (c1 + ci > cntC) continue;
                                    
                                    int sum = ai + bi + carry;
                                    if (sum != ci && sum != ci + 2) continue;
                                    int carry_out = (sum - ci) / 2;
                                    f[i+1][a1+ai][b1+bi][c1+ci][carry_out] = true;
                                }
                            }
                        }
                    }
                }
            }
        }
    }
    
    // 后向DP：g[i][a1][b1][c1][carry]
    bool g[32][32][32][32][2] = {false};
    g[n][cntA][cntB][cntC][0] = true;
    
    for (int i = n-1; i >= 0; i--) {
        for (int a1 = 0; a1 <= cntA; a1++) {
            for (int b1 = 0; b1 <= cntB; b1++) {
                for (int c1 = 0; c1 <= cntC; c1++) {
                    for (int carry = 0; carry <= 1; carry++) {
                        // 枚举当前位的选择
                        for (int ai = 0; ai <= 1; ai++) {
                            if (a1 + ai > cntA) continue;
                            for (int bi = 0; bi <= 1; bi++) {
                                if (b1 + bi > cntB) continue;
                                for (int ci = 0; ci <= 1; ci++) {
                                    if (c1 + ci > cntC) continue;
                                    
                                    int sum = ai + bi + carry;
                                    if (sum != ci && sum != ci + 2) continue;
                                    int carry_out = (sum - ci) / 2;
                                    
                                    if (g[i+1][a1+ai][b1+bi][c1+ci][carry_out]) {
                                        g[i][a1][b1][c1][carry] = true;
                                    }
                                }
                            }
                        }
                    }
                }
            }
        }
    }
    
    // 检查是否有解
    if (!g[0][0][0][0][0]) {
        cout << -1 << endl;
        return 0;
    }
    
    // 贪心构造C'
    int C_val = 0;
    for (int i = n-1; i >= 0; i--) {
        int chosen_c = -1;
        
        // 优先尝试0
        for (int c_bit = 0; c_bit <= 1; c_bit++) {
            bool ok = false;
            
            for (int a1 = 0; a1 <= cntA && !ok; a1++) {
                for (int b1 = 0; b1 <= cntB && !ok; b1++) {
                    for (int c1 = 0; c1 <= cntC && !ok; c1++) {
                        for (int carry_in = 0; carry_in <= 1 && !ok; carry_in++) {
                            if (!f[i][a1][b1][c1][carry_in]) continue;
                            
                            for (int ai = 0; ai <= 1 && !ok; ai++) {
                                if (a1 + ai > cntA) continue;
                                for (int bi = 0; bi <= 1 && !ok; bi++) {
                                    if (b1 + bi > cntB) continue;
                                    
                                    int sum = ai + bi + carry_in;
                                    if (sum != c_bit && sum != c_bit + 2) continue;
                                    int carry_out = (sum - c_bit) / 2;
                                    
                                    if (c1 + c_bit > cntC) continue;
                                    if (g[i+1][a1+ai][b1+bi][c1+c_bit][carry_out]) {
                                        ok = true;
                                    }
                                }
                            }
                        }
                    }
                }
            }
            
            if (ok) {
                chosen_c = c_bit;
                break;
            }
        }
        
        if (chosen_c == -1) {
            // 理论上不会发生，因为已知有解
            cout << -1 << endl;
            return 0;
        }
        
        C_val = (C_val << 1) | chosen_c;
    }
    
    cout << C_val << endl;
    return 0;
}
```

## 示例解释

对于输入 `7 6 9`：
- 二进制：`a=111`, `b=110`, `c=1001`
- 补零：`a=0111`, `b=0110`, `c=1001`（n=4）
- 1的个数：cntA=3, cntB=2, cntC=2
- 重排后得到：`A'=0111`(7), `B'=0011`(3), `C'=1010`(10)
- 满足 `7+3=10`，且10是最小的可能值

## 总结

本题通过动态规划处理二进制加法的约束条件，结合贪心构造得到最小值。关键点在于：
1. 使用两个DP数组分别处理前向和后向状态
2. 从高位到低位贪心构造最小C'
3. 注意处理边界情况（如输入为0的情况）

算法在题目限制范围内（$n \le 31$）可以高效运行。
