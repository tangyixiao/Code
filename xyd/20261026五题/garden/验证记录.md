# garden 验证记录

验证日期：2026-10-26。所有程序均在本机实际运行。

## 正确性与上限测试

执行：

```sh
python3 xyd/20261026五题/garden/verify.py --stress
```

脚本使用 `g++ -std=c++11 -O2` 编译当前 `garden.cpp`，通过题目指定的 `garden.in`、`garden.out` 读写。结果如下：

- 官方附件 `samples/1.in`、`samples/2.in` 全部通过，输出与对应 `.out` 逐 token 一致。第二组规模为 $n=k=q=10^5,m=2\cdot10^5$。
- 穷举 $n=3,k=2$ 的所有合法颜色分配和简单图：每条可能的边选择不存在、权值 $1$、权值 $2$，排除无边图，共 $208$ 组。每组检查全部起点与阈值 $1,2,3$。
- 固定种子 `20261026`，随机生成 $4000$ 组数据，$2\le n\le45$，包含 $k=1$、颜色数大于点数、孤立点、重复边权、环和不同阈值。使用每次重新搜索连通块的 BFS 暴力求答案，并按暴力答案生成连续异或加密的输入；全部一致。
- 上限测试使用另一套实现作为参照：把真实询问离线排序，用普通并查集和颜色字典合并维护答案。该实现也先在全部随机数据中与 BFS 暴力交叉验证。下面四组均为 $n=10^5,m=2\cdot10^5,q=10^5$，全部输出一致。

| 上限数据 | 目的 | C++ 运行时间 | 峰值 RSS |
| --- | --- | ---: | ---: |
| `distinct_colors_deep_tree` | 每点颜色不同，前 $n-1$ 条有效边形成深度 $n-1$ 的重构树 | 0.269 秒 | 54148 KiB |
| `one_color` | $k=1$，大量同色计数相加和模意义幂值 | 0.170 秒 | 28616 KiB |
| `few_colors` | 仅使用 $300$ 种颜色，频繁合并相同颜色 | 0.193 秒 | 55740 KiB |
| `disconnected_equal_weights` | 多个互不连通的千点块，所有边权相同 | 0.223 秒 | 55704 KiB |

运行时间由 Python `time.perf_counter` 包含子进程启动和文件读写测量；峰值 RSS 由独立计量进程的 `resource.getrusage(RUSAGE_CHILDREN)` 获取，仅统计被测 C++ 程序。完整验证耗时 38.45 秒，其中包含编译、数据生成、Python 暴力和参照实现。

## 内存与未定义行为检查

```sh
python3 xyd/20261026五题/garden/verify.py --cases 500 --sanitize
```

使用 `-O1 -g -fsanitize=address,undefined -fno-omit-frame-pointer -no-pie` 编译。检查官方两组附件、上述 $208$ 组穷举和 $500$ 组随机数据，输出全部正确，AddressSanitizer 和 UndefinedBehaviorSanitizer 均无报错。

代码已执行根目录配置的 `clang-format -i`。验证脚本把编译产物和临时输入输出放在临时目录中，不在源码目录留下可执行文件。
