# vine：断藤

## 状态与算法

两棋子位置为 `a,b`，最近公共祖先为 `c`，令 `x=dep[a]-dep[c]`、`y=dep[b]-dep[c]`。棋子沿父亲方向移动；路径碰到另一枚棋子即被挡住，不能经过或落在它所在节点。

- 祖先关系（`x=0` 或 `y=0`）：距离 `1` 是 `Second 0`；距离至少 `2` 是 `First 1`。
- 不在祖先关系上：`x=y>=2` 是 `Second 0`；其余为 `First`。`x=y=1` 有两步胜着，其余情况有一步胜着。

父亲编号小于节点编号，读父亲时即可算深度和倍增祖先表，不需 DFS。预处理 `O(n log n)`，每次查询 `O(log n)`，空间 `O(n log n)`。

## 必败集合证明

必败集合由两类局面组成：祖先关系且间距为 `1`；或分居 LCA 两侧且 `x=y>=2`。

从第一类局面出发，下方棋子被上方棋子挡住，不能移动；上方棋子向上移动后，祖先距离至少为 `2`，后继为必胜局面。从第二类局面出发，任一棋子上移都会令两侧距离不等；移到 LCA 则变成祖先关系且间距至少为 `2`。故必败集合的每个合法后继都在集合外。

对集合外的局面：祖先关系且距离 `d>=2` 时，下方棋子移到上方棋子的儿子节点，得到间距 `1`，且这是唯一胜着。分居 LCA 两侧时，若一侧距离为 `1`，将另一枚棋子移到 LCA，得到间距 `1`；若两侧距离都是 `1`，任一棋子移到 LCA 均获胜，共两步；若较浅距离至少为 `2` 且两侧不等，将较深侧移到与较浅侧等深处，得到 `x=y>=2`，是唯一胜着。于是集合外每个局面都有一步进入必败集合，胜着数与输出一致。

## 提交代码关键部分

倍增 LCA 函数：

```cpp
inline int lca(int x, int y) {
    if (dep[x] < dep[y]) swap(x, y);
    int d = dep[x] - dep[y];
    for (int j = 0; j < L; j++) {
        if (d >> j & 1) x = up[j][x];
    }
    if (x == y) return x;
    for (int j = L - 1; j >= 0; j--) {
        if (up[j][x] != up[j][y]) x = up[j][x], y = up[j][y];
    }
    return up[0][x];
}
```

`solve` 在线建立祖先表，并按 LCA 两侧距离分类。提交版完整 `solve` 如下：

```cpp
inline void solve(int Task_Id) {
    cin >> n >> q;
    dep[1] = 0;
    for (int i = 2; i <= n; i++) {
        cin >> up[0][i];
        dep[i] = dep[up[0][i]] + 1;
        for (int j = 1; j < L; j++) {
            up[j][i] = up[j - 1][up[j - 1][i]];
        }
    }
    while (q--) {
        int a, b;
        cin >> a >> b;
        int c = lca(a, b);
        int x = dep[a] - dep[c], y = dep[b] - dep[c];
        if (!x || !y) {
            int d = max(x, y);
            if (d == 1) {
                cout << "Second 0\n";
            } else {
                cout << "First 1\n";
            }
            continue;
        }
        if (x == y && x >= 2) {
            cout << "Second 0\n";
            continue;
        }
        int moves = (x == 1 && y == 1) ? 2 : 1;
        cout << "First " << moves << '\n';
    }
    return;
}
```

全局数组为 `n,q,dep,up`，函数为 `lca` 和模板入口 `solve(int Task_Id)`。文件保留历史模板。
