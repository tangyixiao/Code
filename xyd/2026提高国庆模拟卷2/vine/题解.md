# vine：断藤

## 状态与算法

两棋子位置为 `a,b`，最近公共祖先为 `c`，令 `x=d[a]-d[c]`、`y=d[b]-d[c]`。棋子沿父亲方向移动；路径碰到另一枚棋子即被挡住，不能经过或落在它所在节点。

- 祖先关系（`x=0` 或 `y=0`）：距离 `1` 是 `Second 0`；距离至少 `2` 是 `First 1`。
- 不在祖先关系上：`x=y>=2` 是 `Second 0`；其余为 `First`。`x=y=1` 有两步胜着，其余情况有一步胜着。

父亲编号小于节点编号，读父亲时即可算深度和倍增祖先表，不需 DFS。预处理 `O(n log n)`，每次查询 `O(log n)`，空间 `O(n log n)`。

## 必败集合证明

必败集合由两类局面组成：祖先关系且间距为 `1`；或分居 LCA 两侧且 `x=y>=2`。

从第一类局面出发，下方棋子被上方棋子挡住，不能移动；上方棋子向上移动后，祖先距离至少为 `2`，后继为必胜局面。从第二类局面出发，任一棋子上移都会令两侧距离不等；移到 LCA 则变成祖先关系且间距至少为 `2`。故必败集合的每个合法后继都在集合外。

对集合外的局面：祖先关系且距离 `d>=2` 时，下方棋子移到上方棋子的儿子节点，得到间距 `1`，且这是唯一胜着。分居 LCA 两侧时，若一侧距离为 `1`，将另一枚棋子移到 LCA，得到间距 `1`；若两侧距离都是 `1`，任一棋子移到 LCA 均获胜，共两步；若较浅距离至少为 `2` 且两侧不等，将较深侧移到与较浅侧等深处，得到 `x=y>=2`，是唯一胜着。于是集合外每个局面都有一步进入必败集合，胜着数与输出一致。

## 最终实现

全局数组和工作变量位于模板末尾的 `TANGYIXIAO` 命名空间；LCA 的 `x,y` 是必要的局部形参。下面代码与提交源码末尾完全一致：

```cpp
namespace TANGYIXIAO {
const int N = 2e5 + 5, L = 2e1;
int n, q, d[N], f[L][N], a, b, c, x, y, z;

inline int lca(int x, int y) {
    if (d[x] < d[y]) swap(x, y);
    z = d[x] - d[y];
    for (int j = 0; j < L; j++) if (z >> j & 1) x = f[j][x];
    if (x == y) return x;
    for (int j = L - 1; j >= 0; j--) if (f[j][x] != f[j][y]) x = f[j][x], y = f[j][y];
    return f[0][x];
}

inline void solve(int Task_Id) {
    cin >> n >> q;
    d[1] = 0;
    for (int i = 2; i <= n; i++) {
        cin >> f[0][i], d[i] = d[f[0][i]] + 1;
        for (int j = 1; j < L; j++) f[j][i] = f[j - 1][f[j - 1][i]];
    }
    while (q--) {
        cin >> a >> b;
        c = lca(a, b), x = d[a] - d[c], y = d[b] - d[c];
        if (!x || !y) {
            if (max(x, y) == 1) cout << "Second 0\n";
            else cout << "First 1\n";
            continue;
        }
        if (x == y && x >= 2) cout << "Second 0\n";
        else cout << "First " << ((x == 1 && y == 1) ? 2 : 1) << '\n';
    }
    return;
}
} // namespace TANGYIXIAO
```
