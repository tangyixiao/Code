## 阅读时抓住的四个问题

1. **缺口：区间里有没有 0？** 没有 0，mex 就是 0，只统计最小值；有 0，最小值就是 0，只统计 mex。这样两个难点不会同时出现。
2. **断藤：什么局面无论怎么动都会交给对手一个必胜局面？** 一种是祖先关系且相邻；另一种是不同分支、到 LCA 的距离相同且至少为 2。找到这两类后，再数能够一步进入它们的走法。
3. **同铸：想让所有数都被 d 整除，每个数最少需要乘多少？** 对归一化后的材料 `b[i]`，答案是 `d/gcd(d,b[i])`。需要补的材料不能超过三块，它们的最小乘数乘积必须整除 `m`。稳定值取的是全部 n 块材料的 gcd，包括没被选中的材料。
4. **印谱：一个符号现在能用，以后也一定能用吗？** 已经出现的符号不能删除，所以必须等到它最后一次不可用的日期之后才能加入。这个变化把复杂的每天集合限制改成了每个印章的一次启用；大天数 DP 随后可以用累计公式计算。

## 编译与验证

在本卷目录打开 PowerShell，单题编译示例：

```powershell
g++ -std=c++11 -O2 notch/notch.cpp -o notch/tmp/notch.exe
```

程序使用题目要求的文件 IO。运行时工作目录中必须有 `notch.in`、`vine.in`、`isogeny.in` 或 `epigraphy.in`，输出对应的 `.out`。附带的检查脚本会准备这些文件，运行目录都在 `tmp` 中，不覆盖 `sample*.out`。

主代理独立验收可以一条命令重跑，包含编译、全部附件样例、小数据暴力、20 万规模构造：

```powershell
python tmp/acceptance.py
```

也可指定题目，例如 `python tmp/acceptance.py --only notch vine`。数学性质的独立枚举保存在 `tmp/independent_checks.py`。各题还保留各自的 `stress.py`、生成器、临时源码和验证数据，具体用法见各题题解与验证记录。

主代理的最终复测结果与时间见 [验收记录.md](验收记录.md)。
