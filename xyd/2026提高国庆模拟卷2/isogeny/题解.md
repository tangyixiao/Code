# 同铸：题解

## 题意与记号

固定三个互不相同的下标，并把正整数 `x,y,z` 分别乘到这三个位置；其余 `a_i` 保持不变，且 `xyz=m`。目标是最大化修改后**全部 n 个数**的 gcd，并统计达到最大值的有序方案数。

令 `G=gcd(a_1,...,a_n)`，`b_i=a_i/G`，于是所有 `b_i` 的 gcd 为 1。修改后的整体 gcd 是 `G` 的倍数。任取一个候选 `D=G*d`，要求修改后的**全部数都被 `G*d` 整除**。由于未选择的位置不变，这些位置必须有 `d|b_i`；对被选中的位置 `i`，乘数至少要补上

`h_i = d / gcd(d,b_i)`。

因此 `d` 可行，当且仅当至多三个 `h_i` 大于 1，且所有大于 1 的 `h_i` 的乘积 `H` 整除 `m`。前一条件表示所有缺少 `d` 因子的下标都能放进被选的三个位置；后一条件表示这些位置各自需要的因子可以放进 `x,y,z`。

注意 `H` 是所有缺口的**乘积**，不是最小公倍数。同一质数在不同位置缺少的指数需要分别由对应乘数补齐。例如 `d=6`、三个归一化值为 `1,2,3` 时，`h` 分别为 `6,3,2`，所以 `H=36`，而 `lcm(6,3,2)=6`。若 `m=36`，恰好能用 `x,y,z=(6,3,2)` 补齐；若只看最小公倍数就会错误地认为 `m=6` 已经足够。

## 计数公式

设 `t` 个位置的 `h_i>1`。这 `t` 个下标必须都选中；还要从原值能被 `d` 整除的 `n-t` 个位置中选出 `3-t` 个。三个不同位置按 `x,y,z` 有序分配有 `3!=6` 种，所以位置方案数为 `6*C(n-t,3-t)`。

除去每个位置必须承担的 `h_i` 后，尚有 `m/H`。对它分解成三个正整数因子的方法数记为 `tau3(m/H)`。若 `m/H=prod p^e`，则每个质数的指数可在三个因子间分配，共 `(e+1)(e+2)/2` 种，因此

`ways(d,m)=6*C(n-t,3-t)*prod_p (e_p+1)(e_p+2)/2`。

枚举 `d` 时只保留合法值，并对 `H` 的每个倍数 `m` 更新最大 `d` 和对应方案数。最大 `d` 对应的计数是在全部数都被 `G*d` 整除的方案中计数；若其中某个方案的 gcd 是 `G*d` 的更大倍数，那么对应的更大候选也可行，与 `d` 已最大矛盾。因此这些方案的实际 gcd 恰为 `G*d`，无需做容斥。

## 枚举范围与复杂度

预处理每个 `d` 的 `cnt[d]=#{i:d|b_i}`。`t<=3` 等价于 `cnt[d]>=n-3`。

当 `n>=4` 时，任取前四个位置，至多三个位置缺少 `d`，所以 `d` 必定整除前四个 `b_i` 中至少一个。只生成这四个数的约数，再用 `cnt` 过滤，避免扫描全部 `d` 后逐个检查所有 `n` 个数。`b_i<=10^6`，每个数至多有 240 个约数。当 `n=3` 时所有下标都要选，直接扫描 `1..max(m)`。

因为 `gcd(b_1,...,b_n)=1`，对每个整除 `d` 的质数幂 `p^e`，至少有一个 `b_i` 不含质因子 `p`；对应的 `h_i` 含有完整的 `p^e`。又每个 `h_i|d`，所以 `lcm(h_1,...,h_n)=d`。而 `H=prod_i h_i`（其中 `h_i=1` 的项不影响乘积），故 `d|H`。合法时 `H|m`，因此 `d<=m<=M`。这也说明 `n=3` 时扫描 `1..M` 不会漏掉候选。

通过筛法计算 `cnt` 与 `tau3`。对每个候选 `d`，只需扫描不同的 `b_i` 值及其频数来算 `t,H`。若合法，就遍历 `H,2H,...,M` 更新答案。

设 `A=max(b_i)`、`M=max(m)`、`B=max(A,M)`、`V` 为不同 `b_i` 数量、`C` 为候选数。频数整除筛耗时 `O(A log A)`；线性筛和逐数分解最小质因数以预处理 `tau3`，耗时保守计为 `O(B log B)`；候选统计需要 `O(CV log A)` 次数级上界（每次 gcd 为 `O(log A)`）；倍数更新满足 `sum_d M/H_d <= sum_{d=1}^M M/d = O(M log M)`，因为 `H_d>=d` 且候选 `d` 互不相同。读入和输出为 `O(n+q)`。总时间为 `O(A log A+B log B+CV log A+M log M+n+q)`，空间为 `O(A+B+n+q)`。

## 正确性要点

1. 若某方案修改后的全部数都被 `G*d` 整除，每个未选位置必须有 `d|b_i`；每个已选位置的乘数必须是 `h_i` 的倍数。因此 `t<=3` 且 `H|m` 是必要条件。
2. 若这两个条件成立，把全部 `t` 个缺口位置选上，再从原值能被 `d` 整除的位置中任选 `3-t` 个。将各自的 `h_i` 放入对应乘数，再把 `m/H` 任意拆成三个因子，就构造出全部数都被 `G*d` 整除的方案，故条件也充分。
3. 对固定合法 `d`，必选的 `t` 个位置及额外 `3-t` 个位置共有 `C(n-t,3-t)` 种；位置到 `x,y,z` 的有序映射有 6 种；剩余因子拆分数为 `tau3(m/H)`。各步独立，计数公式成立。
4. 枚举覆盖所有可行 `d`：合法性推出 `d<=m<=M`；`n=3` 扫描 `1..M`，`n>=4` 时任何可行 `d` 至少整除前四项之一，且 `cnt` 过滤正好保留 `t<=3` 的值。倍数更新覆盖所有 `m` 满足 `H|m` 的查询值。取最大 `d` 即最大 gcd，其计数由第 3 点给出；若计入方案的 gcd 是 `G*d` 的更大倍数，则更大的候选也可行，违背最大性。

## 部分分边界

若只做 `d=1`，总能得到 gcd `G`，但会漏掉能通过三个位置的乘数补齐更大公因子的情况。若只考虑 `m` 的约数而不检查 `t,H`，可能把因子不足以补齐多个位置缺口的值误判为可行。实现利用 `m<=10^6`、`a_i<=10^6` 和“最多三个缺口”的结构覆盖约束范围；满分仅指复杂度与约束的理论覆盖，不代表已经获得评测机 AC 结果。

## 实际提交代码

以下为本题新增的全局数组、辅助函数和 `solve` 实现；模板其余部分沿用原文件。

```cpp
const int MOD = 998244353;
const int LIM = 1000000;
int a[200005], query_m[200005], spf[LIM + 1], tau3[LIM + 1];
int best[LIM + 1], ways[LIM + 1], freq[LIM + 1], divisible[LIM + 1];
int cand[LIM + 1], value_list[LIM + 1];

inline int mod_pow(int a, int e) {
    int r = 1;
    for (; e; e >>= 1, a = (long long)a * a % MOD) { if (e & 1) { r = (long long)r * a % MOD; } }
    return r;
}

inline void make_sieve(int n) {
    static int primes[LIM + 1], pc = 0;
    for (int i = 2; i <= n; i++) {
        if (!spf[i]) { spf[i] = i, primes[++pc] = i; }
        for (int j = 1; j <= pc && primes[j] <= spf[i] && (long long)i * primes[j] <= n; j++) { spf[i * primes[j]] = primes[j]; }
    }
    tau3[1] = 1;
    for (int i = 2; i <= n; i++) {
        int p = spf[i], olde = 0, y = i;
        while (y % p == 0) { y /= p, olde++; }
        tau3[i] = (long long)tau3[y] * (olde + 1) * (olde + 2) / 2 % MOD;
    }
    return;
}

inline void get_divisors(int x, int *d, int &sz) {
    int p[16], e[16], k = 0;
    while (x > 1) { int v = spf[x], c = 0; while (x % v == 0) { x /= v, c++; } p[k] = v, e[k++] = c; }
    d[0] = 1, sz = 1;
    for (int i = 0; i < k; i++) { int old = sz, mul = 1; for (int j = 1; j <= e[i]; j++) { mul *= p[i]; for (int z = 0; z < old; z++) { d[sz++] = d[z] * mul; } } }
    return;
}

inline void solve(int Task_Id) {
    int n, q;
    cin >> n >> q;
    int g = 0, maxb = 1, maxm = 1;
    for (int i = 1; i <= n; i++) { cin >> a[i], g = MATH::gcd(g, a[i]); }
    for (int i = 1; i <= q; i++) { cin >> query_m[i], maxm = max(maxm, query_m[i]); }
    int value_count = 0;
    for (int i = 1; i <= n; i++) { a[i] /= g, maxb = max(maxb, a[i]), freq[a[i]]++; if (freq[a[i]] == 1) { value_list[++value_count] = a[i]; } }
    make_sieve(max(maxb, maxm));
    for (int d = 1; d <= maxb; d++) { for (int x = d; x <= maxb; x += d) { divisible[d] += freq[x]; } }
    int cc = 0;
    if (n == 3) { for (int d = 1; d <= maxm; d++) { cand[cc++] = d; } }
    else {
        int ds[1000], sz = 0;
        for (int i = 1; i <= min(n, 4); i++) {
            get_divisors(a[i], ds, sz);
            for (int j = 0; j < sz; j++) { int d = ds[j]; if (d <= maxm && divisible[d] >= n - 3) { bool seen = false; for (int z = 0; z < cc; z++) { if (cand[z] == d) { seen = true; break; } } if (!seen) { cand[cc++] = d; } } }
        }
    }
    for (int z = 0; z < cc; z++) {
        int d = cand[z], t = 0;
        long long hprod = 1;
        for (int i = 1; i <= value_count; i++) {
            int b = value_list[i], h = d / MATH::gcd(d, b), c = freq[b];
            if (h > 1) {
                t += c;
                if (t > 3) { break; }
                for (int j = 0; j < c; j++) { if (hprod > maxm / h) { hprod = (long long)maxm + 1; break; } hprod *= h; }
                if (hprod > maxm) { break; }
            }
        }
        if (t > 3 || hprod > maxm) { continue; }
        int H = (int)hprod;
        long long choose = 1;
        int k = 3 - t;
        for (int i = 0; i < k; i++) { choose = choose * (n - t - i) % MOD; }
        choose = choose * mod_pow(k == 3 ? 6 : (k == 2 ? 2 : 1), MOD - 2) % MOD;
        int baseways = (long long)6 * choose % MOD;
        for (int m = H; m <= maxm; m += H) {
            if (best[m] < d) { best[m] = d, ways[m] = (long long)baseways * tau3[m / H] % MOD; }
        }
    }
    for (int i = 1; i <= q; i++) { int m = query_m[i]; cout << (long long)g * best[m] << ' ' << ways[m] << '\n'; }
    return;
}
```
