# 印谱

## 先看逐日 DP

把空印章记作 `0`，并令 `dp[s]` 表示处理完今天后、今天恰好盖 `s` 的方案数。若今天盖 `s`，昨天可以盖任意 `t ⊆ s`，所以

```text
new[s] = sum(dp[t])，其中 t ⊆ s
```

但只有题目给出的印章（以及空印章）能被选择；还必须满足今天不早于它的创作日，且 `s ⊆ A[i]`。把 `dp` 做一次子集和 SOS DP，就能同时求出所有 `s` 的转移。逐日做下去，答案是最后一天所有结尾状态之和。这里每天的空印章状态一直有一条“昨天也是空印章”的转移。

这就是 [partial.cpp](partial.cpp) 的 SOS 做法，时间复杂度 `O(n m 2^m)`，空间复杂度 `O(2^m)`。当 `q≤10` 时，该文件改为只在空印章和给定印章之间逐对转移，复杂度 `O(n(q+1)^2)`；这能覆盖表 1、2、4~6，避免 `n=2000,m=10` 时做全状态 SOS。表 3 用 `m=5` 的 SOS 即可，表 7、8 的 `m=8` 也适合逐日 SOS。由此，按给出的约束，表 1~8 都有可行的逐日 DP 路径；表 4~6 的印章构成链、表 8 的印章覆盖率性质无需额外使用。两种转移都不需要利用创作日期的包含单调性。

## 把逐日计算压成多项式

逐日方法的瓶颈是要处理 `n` 天。注意印章一旦盖上就不能被擦掉：若第 `i` 天盖了 `s`，所有后续 `A[k]` 都必须包含 `s`。定义

```text
C[i] = A[i] & A[i+1] & ... & A[n]
```

那么从第 `i` 天起能够一直保留的印章恰好是 `C[i]` 的子集。`C[i]` 随日期向前只会增加。对每个符号 `b`，设 `last[b]` 是最后一个不含它的日期；若从来没有缺失，则为 `0`。印章 `s` 最早可用日期为

```text
r[s] = max(创作日[s], 1 + max(last[b] : b 属于 s))
```

空印章的 `r[0]=1`。不存在的印章以及 `r[s]>n` 的印章都不会产生状态。由于输入保证 `t ⊆ s` 时 `创作日[t] ≤ 创作日[s]`，并且 `s` 的符号集合包含 `t`，有 `r[t] ≤ r[s]`。这保证了计算某个印章时，它的子集多项式都已经就绪。

令 `f[s][i]` 是前 `i` 天的方案中，第 `i` 天恰好以 `s` 结尾的数量。印章可用时，沿用昨天结尾 `s` 的方案仍得到结尾 `s`；除此之外，可以从任意真子集 `t` 切换到 `s`：

```text
f[s][i] - f[s][i-1] = sum(f[t][i-1])，对所有 t 真包含于 s
```

在 `i ≥ r[s]` 后右侧每一项都是次数至多 `|s|-1` 的多项式，因此 `f[s]` 是次数至多 `|s|` 的多项式。使用组合数基表示：

```text
f[s][i] = sum(c[s][k] * C(i,k))
```

组合数基适合做“累计”。恒等式

```text
C(i,k) - C(i-1,k) = C(i-1,k-1)
```

说明 `C(i-1,k-1)` 在每天差分中出现一次，累计到第 `i` 天正好成为 `C(i,k)`。因此若所有真子集的系数和为 `g[k]`，则 `c[s][k+1]=g[k]`。此外 `f[s][r[s]-1]=0`，所以

```text
c[s][0] = -sum(c[s][k] * C(r[s]-1,k)), k>=1
```

这个等式只用于确定常数项。`i<r[s]` 时，上述多项式只是一个形式表达，不能当作真实的逐日 DP 状态；程序只在 `i=n` 且 `n≥r[s]` 时取值。

### 两个符号的例子

假设空印章和所有非空印章都在第 1 天可用，且每天 `A[i]=3`。空印章有 `f[0][i]=1`。对单符号印章，差分恒为 `1`，所以 `f[1][i]=C(i,1)=i`，`f[2][i]=i`。对印章 `3`，它的差分是 `1+f[1][i-1]+f[2][i-1]`，于是

```text
f[3][i] = C(i,1) + 2*C(i,2) = i^2
```

第 `n` 天总方案数为 `1 + 2n + n^2 = (n+1)^2`，也对应两个符号各自选择一个“不晚于最后一天的首次出现日”。

## 子集求和与复杂度

按印章的符号数 `r=1..m` 分层。第 `r` 层的每个印章只需要知道所有严格子集的 `k=0..r-1` 次系数和。把较小层已经得到的系数放入临时数组，对每个系数维度做一次子集 SOS；取出第 `r` 层印章的和后，就得到它的 `c[s][1..r]`。再用 `f[s][r[s]-1]=0` 求常数项。

最后把所有有效印章在第 `n` 天的值相加。主要复杂度为 `O(m^3 2^m + nm)`，空间复杂度 `O(m2^m + nm)`；其中二项式系数表用来常数时间读取 `C(n,k)` 和 `C(r[s]-1,k)`。`m≤16` 时，SOS 的主体约为 1.43 亿个简单系数槽位操作（实际加法约一半）。本机完整规模执行程序测得约 `101~142 ms`，主代理独立重跑测得约 `106~125 ms`；这些是各自机器的实测，不代表 OJ 评测机保证。

## 提交代码

`epigraphy.cpp` 保留原有模板，只在末尾 `namespace TANGYIXIAO` 中实现 `solve`。代码中 `l[x]` 是数学定义里的 `last[x]`，`d[s]` 是 `r[s]`（有效开始日），`pc[s]` 是 `|s|`，`c[s][k]` 存系数，`b[i][k]` 存组合数，`vis[s]` 表示印章存在。实现里的 `f` 是 SOS 临时数组，与上文数学函数 `f[s][i]` 无关。下面是从源文件末尾命名空间摘出的实际代码：

```cpp
const int N = 2e5 + 5, M = 1 << 16, mod = 998244353;
int a[N], l[16], d[M], pc[M], c[M][17], f[M][17], b[N][17];
int n, m, q, lim;
bool vis[M];
long long ans;

inline void solve(int) {
    cin >> n >> m >> q;
    lim = 1 << m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int s = 1; s < lim; s++) pc[s] = pc[s >> 1] + (s & 1);
    for (int i = 1; i <= n; i++) for (int x = 0; x < m; x++) if (!(a[i] >> x & 1)) l[x] = i;
    vis[0] = true, d[0] = 1;
    for (int i = 0, s, day; i < q; i++) {
        cin >> s >> day;
        vis[s] = true, d[s] = day;
        for (int x = 0; x < m; x++) if (s >> x & 1) d[s] = max(d[s], l[x] + 1);
    }
    for (int i = 0; i <= n; i++) {
        b[i][0] = 1;
        for (int k = 1; k <= m; k++) b[i][k] = i ? (b[i - 1][k] + b[i - 1][k - 1]) % mod : 0;
    }
    c[0][0] = 1;
    for (int r = 1; r <= m; r++) {
        for (int s = 0; s < lim; s++) for (int k = 0; k < r; k++) f[s][k] = pc[s] < r ? c[s][k] : 0;
        for (int x = 0; x < m; x++) for (int s = 0; s < lim; s++) if (s >> x & 1) for (int k = 0; k < r; k++) { f[s][k] += f[s ^ (1 << x)][k]; if (f[s][k] >= mod) f[s][k] -= mod; }
        for (int s = 1; s < lim; s++) if (pc[s] == r && vis[s] && d[s] <= n) {
            for (int k = 0; k < r; k++) c[s][k + 1] = f[s][k];
            long long z = 0;
            for (int k = 1; k <= r; k++) z = (z + 1LL * c[s][k] * b[d[s] - 1][k]) % mod;
            c[s][0] = (mod - z) % mod;
        }
    }
    for (int s = 0; s < lim; s++) if (vis[s] && d[s] <= n)
        for (int k = 0; k <= pc[s]; k++) ans = (ans + 1LL * c[s][k] * b[n][k]) % mod;
    cout << ans << '
';
}
```

`stress.py` 用固定种子生成满足创作日期单调性的随机小数据；其暴力校验逐日枚举昨日、今日的印章对，独立于组合数多项式推导。失败时会保留 `tmp/failed.in`、`tmp/failed.expected` 和 `tmp/failed.actual`。`generate_max.py` 生成最大规模压力数据，所有印章都出现且创作日按符号数递增。
