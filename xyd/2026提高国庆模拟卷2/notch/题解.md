# notch：缺口

## 思路

按区间是否包含 `0` 分类。不含 `0` 时 `mex=0`，对位置 `i`，设左右最近的严格更小元素位置为 `L_i,R_i`（不存在取 `0,n+1`）。作为区间左端点，可从 `L_i+1..i` 中选择，共 `i-L_i` 种；右端点可从 `i..R_i-1` 中选择，共 `R_i-i` 种。因此 `a[i]` 作为区间最小值的区间数为 `(i-L_i)(R_i-i)`。单调栈求边界，给答案 `a[i]` 加上该数量；`a[i]=0` 跳过。

包含 `0` 的区间最小值为 `0`。令 `F(k)` 为同时包含值 `0..k-1` 的区间数。若这些值位置最左、最右端点为 `L_k,R_k`，则 `F(k)=L_k(n-R_k+1)`。恰好 `mex=k` 的区间数是 `F(k)-F(k+1)`。要包含所有 `0..k-1`，区间左端点必须不大于它们的最左位置 `L_k`，有 `L_k` 种；右端点必须不小于最右位置 `R_k`，有 `n-R_k+1` 种，故 `F(k)=L_k(n-R_k+1)`。扫描位置即可维护包络。总时间、空间均为 `O(n)`，计数用 `long long`。

## 正确性要点

单调栈的边界保证区间含 `i` 且不含任何更小值；每个不含 `0` 的区间只有唯一最小值位置。对包含 `0` 的区间，包含 `0..k-1` 但不包含全部 `0..k` 正是 `mex=k`；覆盖最左、最右位置的区间共有 `F(k)` 个。两类区间互斥且穷尽。

## 提交代码关键部分

`solve` 用 `st` 单调栈求非零最小值贡献：

```cpp
int top = 0;
for (int i = 1; i <= n; i++) {
    while (top && a[st[top]] > a[i]) right_pos[st[top--]] = i;
    left_pos[i] = top ? st[top] : 0;
    st[++top] = i;
}
while (top) right_pos[st[top--]] = n + 1;
for (int i = 1; i <= n; i++) {
    if (a[i] > 0) ans[a[i]] += 1LL * (i - left_pos[i]) * (right_pos[i] - i);
}
```

mex 部分从 `F(1)` 开始，依次减去 `F(k+1)`，最后 `F(n)` 对应 `mex=n`：

```cpp
int lo = pos[0], hi = pos[0];
long long prev = 1LL * lo * (n - hi + 1);
for (int k = 1; k < n; k++) {
    lo = min(lo, pos[k]);
    hi = max(hi, pos[k]);
    long long cur = 1LL * lo * (n - hi + 1);
    ans[k] += prev - cur;
    prev = cur;
}
ans[n] += prev;
```

全局数组：`n,a,pos,st,left_pos,right_pos,ans`；提交版的完整 `solve` 如下（其余约 600 行历史模板保留原样）：

```cpp
inline void solve(int Task_Id) {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pos[a[i]] = i;
    }
    int top = 0;
    for (int i = 1; i <= n; i++) {
        while (top && a[st[top]] > a[i]) {
            right_pos[st[top--]] = i;
        }
        left_pos[i] = top ? st[top] : 0;
        st[++top] = i;
    }
    while (top) {
        right_pos[st[top--]] = n + 1;
    }
    for (int i = 1; i <= n; i++) {
        if (a[i] > 0) {
            ans[a[i]] += 1LL * (i - left_pos[i]) * (right_pos[i] - i);
        }
    }
    int lo = pos[0], hi = pos[0];
    long long prev = 1LL * lo * (n - hi + 1);
    for (int k = 1; k < n; k++) {
        lo = min(lo, pos[k]);
        hi = max(hi, pos[k]);
        long long cur = 1LL * lo * (n - hi + 1);
        ans[k] += prev - cur;
        prev = cur;
    }
    ans[n] += prev;
    for (int k = 1; k <= n; k++) {
        cout << ans[k] << (k == n ? '\n' : ' ');
    }
    return;
}
```

当 `n=1`、排列为 `[0]` 时，唯一区间的 `min+mex=0+1=1`，故输出 `1`。
