# notch：缺口

## 思路

按区间是否包含 `0` 分类。不含 `0` 时 `mex=0`，对位置 `i`，设左右最近的严格更小元素位置为 `L_i,R_i`（不存在取 `0,n+1`）。作为区间左端点，可从 `L_i+1..i` 中选择，共 `i-L_i` 种；右端点可从 `i..R_i-1` 中选择，共 `R_i-i` 种。因此 `a[i]` 作为区间最小值的区间数为 `(i-L_i)(R_i-i)`。单调栈求边界，给答案 `a[i]` 加上该数量；`a[i]=0` 跳过。

包含 `0` 的区间最小值为 `0`。令 `F(k)` 为同时包含值 `0..k-1` 的区间数。若这些值位置最左、最右端点为 `L_k,R_k`，则 `F(k)=L_k(n-R_k+1)`。恰好 `mex=k` 的区间数是 `F(k)-F(k+1)`。扫描位置即可维护两端点包络。总时间、空间均为 `O(n)`，计数用 `long long`。

## 正确性要点

单调栈的边界保证区间含 `i` 且不含任何更小值；每个不含 `0` 的区间只有唯一最小值位置。对包含 `0` 的区间，包含 `0..k-1` 但不包含全部 `0..k` 正是 `mex=k`；覆盖最左、最右位置的区间共有 `F(k)` 个。两类区间互斥且穷尽。

## 最终实现

代码中的 `x,y` 分别记录 `L_k,R_k`，`v` 记录当前 `F(k)`；全局变量位于模板末尾的 `TANGYIXIAO` 命名空间。以下与提交源码末尾完全一致：

```cpp
namespace TANGYIXIAO {
const int N = 2e5 + 5;
int n, t, x, y, a[N], p[N], st[N], l[N], r[N];
long long v, ans[N];

inline void solve(int Task_Id) {
    cin >> n;
    for (int i = 1; i <= n; i++) { cin >> a[i], p[a[i]] = i; }
    t = 0;
    for (int i = 1; i <= n; i++) {
        for (; t && a[st[t]] > a[i];) { r[st[t--]] = i; }
        l[i] = t ? st[t] : 0, st[++t] = i;
    }
    for (; t;) { r[st[t--]] = n + 1; }
    for (int i = 1; i <= n; i++) {
        if (a[i]) { ans[a[i]] += 1LL * (i - l[i]) * (r[i] - i); }
    }
    x = y = p[0], v = 1LL * x * (n - y + 1);
    for (int k = 1; k < n; k++) { x = min(x, p[k]), y = max(y, p[k]), ans[k] += v - 1LL * x * (n - y + 1), v = 1LL * x * (n - y + 1); }
    ans[n] += v;
    for (int k = 1; k <= n; k++) { cout << ans[k] << (k == n ? '\n' : ' '); }
    return;
}
} // namespace TANGYIXIAO
```

当 `n=1`、排列为 `[0]` 时，唯一区间的 `min+mex=0+1=1`，故输出 `1`。
